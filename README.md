# API Gateway Project

A microservices project with a custom-built API Gateway in front of independent services (User, Order), demonstrating routing, auth, rate limiting, load balancing, and async processing.

## Services
- **api-gateway** — routing, auth, rate limiting, load balancing, logging
- **user-service** — user registration, login, profile
- **order-service** — order creation and management

## Status
🚧 Work in progress

## Tech Stack
- Node.js / Express
- MySQL (raw SQL, no ORM)
- Redis
- BullMQ
- Docker / Docker Compose
